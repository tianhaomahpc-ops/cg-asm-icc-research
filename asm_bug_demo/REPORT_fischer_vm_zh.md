# Fischer 回收:按"用每步最新 Vm"逐条实测

> 对象:`forward_ecg.cpp`(分支 `cardiac-sim-fakegeo`)里 Sys2 的时间回收。
> 容器里没有 MFEM/PETSc,所以在一个**结构相同的可复现模型问题**上做(`fischer_vm_test.c`),
> 三个工况、14 种初值方案、每步一次干净冷启动做基准。原始数据 `fischer_vm_regime{0,1,2}.csv`,
> 汇总图 `fig_fischer_vm.png`。改真代码的补丁 `fischer_sliding_window.patch`(可 `git apply`)。

---

## 0. 一句话结论

**"用最新 Vm 定系数"这条路实测确认没有余量(A-范数误差反而差 1.26–1.44 倍);但顺着测下去撞到一个更大的问题:现行 Fischer 的滑窗淘汰规则是错的。** `fisch_P.erase(fisch_P.begin())`(`forward_ecg.cpp:2604`)删掉的是"最旧的**正交基向量**",这不等于"忘掉最旧的**解**"——它把所有留存向量共有的主方向一并删除。在复现你们真机三个基准(warm −2%、physics −5%、现行 Fischer −69%)的工况下,把窗口改对:**−69% → −98.6%**。

## 2. 逐条回答"用最新 Vm"

### 2.1 用最新 Vm 定系数:确认没有收益

同一个窗口(最近 16 个解),两种系数规则:A-最优(`G c = f`,`f_k=⟨u^k,b⟩`)vs 用最新 Vm 在历史 Vm 上最小二乘。

| | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| 平均 ‖x*−x0‖_A(A-最优) | 4.70 | 28.7 | 0.472 |
| 平均 ‖x*−x0‖_A(用最新 Vm 定系数) | 6.78 | 39.5 | 0.597 |
| **比值** | **1.44** | **1.38** | **1.26** |

**A-范数上必然更差,符合投影最优性**(在给定子空间里 A-正交投影是唯一最优)。

有意思的是迭代数上两者几乎一样(甚至偶尔更少:−57.8% vs −54.9%)。**因为迭代数由残差 2-范数决定,不是 A-范数误差,两者不单调相关**——这也解释了为什么"把初值做得更好一点"经常换不到迭代。

→ 结论:换系数规则没有精度收益,还多一份 Vm 快照存储和一次归约。**不值得做**。

### 2.2 physics 初值 `x0=c*·Vm`(真机 −2%)

测试台:−3.0% / −2.8% / −5.0%(三工况)。**复现了真机的量级,确认这条没用**——`u_e≈−c·Vm` 只在等各向异性下成立。

### 2.3 用 ΔVm 做增量预测 / 富化:无效

`b^n − b^{n-1} = −K_i ΔVm` 是免费的,拿它做增量预测或给子空间加方向:

| 方案 | regime 0 | regime 1 | regime 2 | 成本 |
|---|---|---|---|---|
| warm(基准) | −28.0% | −46.3% | −2.1% | 0 |
| warm + SGS3(ΔVm) | −24.8% | −48.0% | **+2.6%(更慢)** | 3 次扫描 |
| warm + SGS12(ΔVm) | −27.8% | −50.6% | −0.6% | 12 次扫描 |
| 真滑窗 + ΔVm 富化 | −55.0%(vs −54.9%) | −48.9%(vs −48.8%) | −98.5%(vs −98.6%) | ~5 次 matvec |

**全部拒绝**:增量预测大多不如 warm 本身,富化只值 ±0.1 个百分点却要 ~5 次 matvec。

### 2.4 相位分散淘汰:拒绝(而且我上次说反了方向)

上次我说"淘汰与当前 Vm 最不相关的那个"——**那个方向是错的**:平台期这条规则恰好会把 QRS 锚点扔掉。实测的是修正版"淘汰最冗余的相位"(保持窗口相位多样):

| | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| 真滑窗(淘汰最旧的解) | −54.9% | −48.8% | −98.6% |
| 真滑窗 + 相位分散淘汰 | **−44.9%(更差)** | −51.6% | −98.8% |
| 真滑窗 + 窗口 ×3 | −53.1% | −49.0% | −98.9% |

淘汰规则的花样(和三倍内存)一律只值 ±3 个百分点。**值钱的只有一件事:窗口是不是真的"最近 m 个解"。**

### 2.5 η 门控(零 matvec 预判):成立

η = 用最新 Vm 在历史 Vm 快照上做最小二乘的相对残差(m 个点积 + 一次 m×m 小解,**零 matvec**),用来预判"这一步初值会不会直接落进容差":

| 门限 1e-4 | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| 召回(0 迭代步有没有被漏掉) | **1.00** | **1.00** | **1.00** |
| 门内准确率 | 0.71 | 0.95 | 0.75 |

**η ≥ 1e-4 的步从来没有命中过**(三个工况、2400 多步,零假阴性)。所以它是个可靠的"这步别指望初值"信号,可以拿来做调度(该上粗空间/deflation 的步不要浪费在初值上)。它**不改精度**,改的是"知道自己行不行"。

## 3. 测出来的真问题:滑窗淘汰规则

### 3.1 现象

| 总迭代相对 cold | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| **现行实现(淘汰最旧正交基向量)** | **+2.2%(比冷启动还慢)** | −7.4% | −69.1% |
| 满了就整体重启 | −53.2% | −20.4% | −76.8% |
| **真滑窗(最近 m 个解 + Gram 定系数)** | **−54.9%** | **−48.8%** | **−98.6%** |

regime 2 的现行实现是 −69.1%,和你们真机的 −69% 撞在一起;**同一工况下修好窗口是 −98.6%**(56890 → 804 迭代,350 步里 259 步 0 迭代)。

> 「投影怎么会比冷启动还慢?」不矛盾:A-正交投影的 **A-范数误差**永远 ≤ 冷启动的 ‖x*‖_A,但迭代数由**残差 2-范数**和误差的**谱分布**决定。投影把低频分量削掉后,剩下的高频分量被 A 放大,残差 2-范数反而比 x0=0 时更大 —— 这也是 §2.1 里 A-范数更差的 vmfit 迭代反而略少的同一个原因。

### 3.2 机理:窗口里连"上一步的解"都表示不出来

诊断量:把上一步的解投影到当前窗口上,看相对 A-范数残差
`‖u^{n-1} − Π u^{n-1}‖_A / ‖u^{n-1}‖_A`。真滑窗按定义恒为 0。

| | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| 现行实现(均值 / 峰值) | 0.191 / 0.766 | 0.109 / 0.964 | 0.099 / 0.979 |

原因很简单:`p_1..p_m` 是对 `u^1..u^m` 逐个 A-正交化的结果,**每个后来的向量都被减去了 `p_0` 方向的分量**;删掉 `p_0`,所有解共有的主方向就没了,剩下的向量再也补不回来。下一步的新解只好把它重新学一遍——于是基永远在"学了又丢"(regime 0:接受 1011 次、淘汰 995 次)。

### 3.3 绝对阈值 1e-12 的角色(上次我猜对了一半)

先更正一处:我上次说"改相对阈值 + 不合格就不淘汰",**代码里淘汰本来就在接受分支内**(`:2597` 的 `if (nrm>1e-12)` 里面),所以只有阈值那一半要改。

实测:

| | regime 0 | regime 1 | regime 2 |
|---|---|---|---|
| 绝对阈值触发拒收次数 | 0 / 1011 | 0 / 1044 | **346 / 350** |
| 现行(绝对 1e-12) | +2.2% | −7.4% | −69.1% |
| **只把阈值改成相对 1e-3·‖u‖_A** | +2.2%(无差别) | −7.4%(无差别) | **−76.8%(+7.7pp)** |
| 基的 A-正交性损失(regime 2) | — | — | 2.3e-08 → **6.7e-15** |

机理正如猜测:近共线时余量是噪声量级,绝对阈值把它归一化成单位 A-范数收进基,**同时触发一次淘汰**;相对阈值直接拒收 ⇒ 从不淘汰 ⇒ 窗口完好,并且自动发现了这个工况的**内在维数 4**(只接受了 4 个向量)。

但这只是止损:**−76.8% 仍然远不如把窗口修对的 −98.6%**。

## 4. 修法 + 补丁

**做法**:不再维护正交基,直接保留原始快照 `U`、`AU=K_ie·U`,维护 m×m 的 Gram `G_kl=⟨u^k, A u^l⟩`;每步解 `G c = f`(`f_k=⟨u^k,b⟩`,截断伪逆)得到 `x0=Σ c_k u^k`。这就是"最近 m 个解张成的子空间上的 A-正交投影"——**没淘汰时与原实现逐位等价,有淘汰时才是对的**。

成本反而更低:

| 每步 | 现行 | 修后 |
|---|---|---|
| Allreduce | 4(投影 1 + CGS2 2 + 范数 1) | **2**(f 一次 + Gram 新行一次) |
| 向量运算 | ~5m 次 axpy/点积 | ~m 次 |
| matvec | 1 | 1 |
| 新增 | — | 一次 m×m 局部特征分解(m=16,几千 flop;`dsyev_` 已在 `forward_ecg.cpp:51` 链好) |

**补丁**:`asm_bug_demo/fischer_sliding_window.patch`,在 `cardiac-sim-fakegeo` 上 `git apply --check` 干净通过。

**补丁的单元测试**:容器里编译不了 MFEM/PETSc,所以把补丁新增的簿记(增量 Gram + 淘汰时的行列删除 + `gram_solve`)**原样搬进** `fischer_gram_selftest.cpp`(mock 掉 mfem::Vector / MPI / LAPACK),检查两件与实现无关的事:

```
max rel Gram error     : 9.499e-16   (增量维护 vs 从头重算)
max rel <u^k, b-A x0>  : 2.347e-11   (A-正交投影的定义性质,不经过 gram_solve)
Allreduces: new=40  old-equivalent=324
SELFTEST PASS
```

## 6. 边界与诚实说明

- 这是**模型问题**:结构(奇异性、非等各向异性、移动前沿、多拍)对得上,但网格、预条件(Jacobi 而非 bjacobi+ICC)、并行都不同。**绝对数字不可直接搬到真机**。
- 可对照的三个量在 regime 2 上和真机吻合(warm −2% vs 真机 −4%;physics −5% vs 真机 −2%;现行 Fischer −69.1% vs 真机 −69%),说明工况刻画抓对了。
- regime 2 是 4 维合成流形,16 维窗口天生能张住,所以 −98.6% 带有上界性质;真机上能拿回多少,**只能 apply 补丁跑一次 `forward_ecg -fischer` 才知道**。
- 三个工况里 warm 的表现差得很远(−28% / −46% / −2%),说明真机 warm −4% 对应的正是 regime 2 那类"低维但快变"。

## 7. 建议的下一步(按性价比)

1. **apply 补丁**,跑 `forward_ecg -fischer -T 80 -dt 0.02`(np=8),看 `[FISCHER]` 那张表的 Fischer 一行;同时维护归约应从 314 再降一半。
2. 不想动结构的话:`:2597` 的 `1e-12` 改成 `1e-3*ref`(一行),regime 2 里值 +7.7pp,并且顺手修掉正交性污染(2.3e-08 → 6.7e-15)。
3. **η 门控**:存 Vm 快照,每步一次 m×m 最小二乘(零 matvec),预判该不该在这一步指望初值——对 3000 核省同步的设计正好对口。
4. 剩下的硬步仍然只能靠 deflation / 粗空间(你们已有 76→15 的数据),初值这条路在那儿确实封顶。
