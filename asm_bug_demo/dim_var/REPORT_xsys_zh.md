# 跨系统共享粗空间(Sys1 → Sys2):完整实验与报告

*目标:在同一张心脏网格上,把一套混合粗空间"只建一次"并复用到整个 Sys1→Sys2 范围
与时间步序列,验证它能否超过 Task-3 的 1.6×。代理实验在 `xsys_proto.py`(2D 精确谱
NumPy),对标真实管道的 Task-3 结果。*

工具:`asm_spectral.py`(算子/谱)、`coarse_proto.py`(混合粗空间)、`xsys_proto.py`(本实验)。
数据:`results/xsys_sigma.csv`、`results/xsys_sequence.csv`;图:`fig_xsys_sigma.png`、`fig_xsys_sequence.png`。

---

## 1. 背景与思路

三系统更正后的结构:**Sys1(monodomain)与 Sys2(u_e 恢复)同一张心脏网格**;Sys3(Torso)
是另一张网格、从 Sys2 拿 Dirichlet 界面数据(本报告聚焦同网格的 Sys1↔Sys2,Sys3 见 §5)。

把两者建模为**同一刚度 K 在不同质量/时间步移位 σ 下**:

```
A(σ) = K + σ·I      σ 大  ≈ Sys1((1/dt)、质量主导、易)
                    σ → 0 ≈ Sys2(纯 Neumann、奇异、最难)
```

归因研究已证:**σ/边界控制 λmin(信息传递),σ→0 时 κ ∝ 1/σ**(常数模无人锚)。
overlap/sASM 够不着这条 λmin;只有粗空间能补。本实验的核心对象:

**混合粗空间(只建一次,σ 无关、系数派生,非 GenEO):**
```
V0 = [ 少量移位不变 (K,M) 低谱模 ]   (平滑全局 + 常数/零模;对所有 σ 通用)
   + [ 已知系数 A-调和模 ]           (对比度/各向异性;从已知电导区构造)
两层加性:  M2⁻¹ = M1⁻¹(sASM) + V0 (V0ᵀA V0)⁺ V0ᵀ      (对称,CG 可用;纯 Neumann 用 pinv 去奇异)
```

---

## 2. 实验设计

- 网格:2D,33²=1089 节点,4×4=16 子域,overlap=1,sASM + ICC(0) 作一层。
- 系数:`const`(纯移位场景)与 `layers`(对比度 10,触发已知系数模,m=7)。
- **Part A — σ 扫描(Sys1→Sys2)**:V0 只建一次(从 σ=0 的 K + 已知系数),σ∈{10³,10,1,0.1,0.01,10⁻⁴}
  逐个求解,对比 one-level sASM 与 two-level(共享 V0)的迭代数与 κ。
- **Part B — 时间步序列(Sys2 端,σ=0.01)**:RHS = 沿 x 移动的"前沿"高斯源(零均值、相容),
  T=12 步,对比 one-level cold / two-level cold / two-level warm(x₀=上一步解)的总 CG 迭代,
  这是 Task-3"共享粗空间 + warm"的代理。

---

## 3. 结果

### Part A:一套粗空间压平整个 Sys1→Sys2 范围(`fig_xsys_sigma.png`)

| σ(大→小 = Sys1→Sys2) | one-level κ | two-level κ | one-level iter | two-level iter |
|:--|:--|:--|:--:|:--:|
| const  σ=10 | 90 | **19** | 56 | **39** |
| const  σ=0.01 | **88000** | **24**(平) | 72 | **42** |
| const  σ=10⁻⁴ | →∞ | (奇异,pinv) | 79 | **43** |
| layers σ=0.01 | **4.7e5** | **81**(平) | 76 | **45** |

- **one-level κ ∝ 1/σ**,σ→0 时爆到 4.7e5(Sys2 难点);**two-level κ 与 σ 无关**(const ~24、layers ~81),
  迭代被钉在 ~42–45。**同一个 V0(只建一次)对整段 σ 都有效** —— 这就是"跨 Sys1/Sys2 复用"。
- 含已知系数 A-调和模(layers,m=7)时,对比度也被一并压住(κ 81 而非 4.7e5)。

### Part B:Sys2 端时间步序列(`fig_xsys_sequence.png`)

| 方法 | 12 步总 CG 迭代 | 相对 one-level |
|:--|:--:|:--:|
| one-level sASM, cold | 919 | 1.00× |
| two-level(共享粗), cold | 548 | **1.68×** |
| two-level + warm start | 541 | **1.70×** |

- **共享粗空间是主杠杆(1.68×);warm-start 仅边际(→1.70×)** —— 与 Task-3 的结论**一致**
  (Task-3:avg CG 46→28.9 ≈ 1.6×,且 POD/warm 因前沿高秩而次要)。本代理 1.68× **达到并略超** 1.6×。

## 4. 与 Task-3 的对照

| | Task-3(真实管道) | 本代理(xsys_proto) |
|:--|:--|:--|
| 主结论 | 共享 Nicolaides 粗空间是主因,warm 次要,1.6× | 共享混合粗空间是主因,warm 次要,**1.68×** |
| 粗空间 | Nicolaides(每子域一常数) | **混合:移位不变谱 + 已知系数 A-调和**(更省模、含对比度鲁棒) |
| 新增 | — | 一套 V0 跨整段 σ(Sys1↔Sys2)解析复用;Sys2 零模由常数谱模自然 deflate |

本实验**复现了 Task-3 的定性结论**,并把粗空间从 Nicolaides 升级为**移位不变 + 已知系数**的
混合构造(对比度更鲁棒、且严格说明了"为什么一套能跨 σ 复用")。

## 5. 跨网格的 Sys3(下一阶段)

Sys3 在**另一张躯干网格**上、经界面 Dirichlet(u_e)耦合,**不能直接共享心脏网格的 V0**。
复用机制是:在躯干网格上独立建同型混合粗空间(一次、跨时间步复用)+ **前沿跟随**
(用 Sys1 的去极化前沿定位活跃界面区)。这是单独的下一阶段工作。

---

## 6. 真实管道实现配方

1. 在心脏网格上,从 **A2 = K_{σi+σe}** 取少量低谱模(含常数 = Sys2 零空间)+ 从**已知 σi/σe 区域/纤维场**
   构造 A-调和模 → 拼成 V0(一次构建)。
2. 两层加性 PCSHELL:`M2⁻¹ = M1⁻¹(sASM) + V0 A0⁺ V0ᵀ`,A0=V0ᵀA V0;Sys2 用 pinv/deflation 去常数零模。
3. 跨时间步:σ=1/dt 变化时**同一 V0 复用**(移位不变);warm-start 作边际增益。
4. `xsys_precond.c` 源码不在树里(仅二进制)→ 需按此配方重建后在 PETSc 3.24 上规模验证。

---

## 7. 局限(诚实)

- 代理为**标量对比度**(FD 调和平均),非真实**张量各向异性**(纤维场)——构造原理相同,
  真实张量待接到 FEM(`fem_build.py` 的 b/d 系数)。
- σ=0 精确奇异用 `pinv(A0)` 去常数零模;真实 Sys2 同理(常数模在 V0 内)。
- 1.68× 在 2D 代理上测得,对标 Task-3 真实管道的 1.6×;绝对数值需在真实心脏网格 + PETSc 规模上复核。
