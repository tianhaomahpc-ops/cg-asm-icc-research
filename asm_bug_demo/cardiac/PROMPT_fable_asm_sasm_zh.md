# Prompt(抽象数值问题:ASM vs sASM 的 overlap 反常)

## 1. 问题定义

**稀疏对称正定(SPD)线性系统的并行预条件研究**,目标**强可扩展到 ~3000 核**。三维非结构四面体 P1 有限元离散;一个**细长盒子区域 Ω₁(边长比约 20:7:3)** conforming 嵌在**大盒子 Ω₂(50³)** 里。每时间步**顺序解三个 SPD 系统**,都用 **CG + 加性 Schwarz(1 子域/进程,本地不完全 Cholesky ICC(0))**:

| 系统 | 算子 | 类型 | 边界 |
|---|---|---|---|
| **S1** | $A_1=\tfrac{1}{\Delta t}M+\tfrac12K_1$(质量+各向异性刚度) | 抛物、**质量主导**、良态 | Neumann |
| **S2**(主目标) | $K_2\,u=f$,各向异性刚度(纵向系数≫横向,主轴沿最长轴 x) | 椭圆、**纯 Neumann→奇异**(核=常数) | 纯 Neumann,奇异 |
| **S3** | $K_3\,\varphi=0$ | 椭圆、大区域 | **界面 Dirichlet** + 外边界 Neumann |

规模:每进程数万自由度、进程数很大 → **通信受限区**(每迭代被全局归约 Allreduce 延迟主导)。

## 2. 目前用的两个方法:形式

设 $R_i$ = 限制到(带重叠 overlap δ 的)子域 $i$ 的算子,$A_i=R_iAR_i^{\!\top}$ = 装配主子阵,$\tilde A_i^{-1}$ = **一次 ICC(0) apply**(不精确本地解),$m(j)$ = 覆盖自由度 $j$ 的子域数(**重数/multiplicity**)。

**ASM(加性 Schwarz,不缩放 / BASIC)**:
$$M_{\text{ASM}}^{-1}=\sum_{i=1}^{N} R_i^{\!\top}\,\tilde A_i^{-1}\,R_i$$

**sASM(对称多重数缩放加性 Schwarz)**:
$$M_{\text{sASM}}^{-1}=D^{-1/2}\Big(\sum_{i=1}^{N} R_i^{\!\top}\,\tilde A_i^{-1}\,R_i\Big)D^{-1/2},\qquad D=\mathrm{diag}\big(m(j)\big)$$
等价地 $M^{-1}=\sum_i R_i^{\!\top}D_i^{1/2}\tilde A_i^{-1}D_i^{1/2}R_i$,满足单位分解 $\sum_i R_i^{\!\top}D_iR_i=I$。

**两者都对称 SPD(配 CG 合法)、都用同样的 ICC(0) 本地解;唯一区别是 $D^{-1/2}$ 重数缩放。** δ=0(无重叠)时 $m(j)\equiv1$,两者**完全相同**。

## 3. 两个方法的结果(实测,CG 到 rtol 1e-8,ICC(0),8 子域)

overlap O = 0/1/2,迭代数:

| 系统 | O | **ASM** | **sASM** |
|---|---|---|---|
| **S1** 抛物(良态) | 0 / 1 / 2 | 13 / **18 / 19** | 13 / **8 / 8** |
| **S2** 奇异椭圆(难) | 0 / 1 / 2 | 79 / **117 / 123** | 79 / **73 / 71** |
| **S3** Dirichlet 椭圆 | 0 / 1 / 2 | 66 / **93 / 109** | 66 / **55 / 53** |

**核心现象("overlap 反常")**:
- **ASM:迭代数随 overlap 上升**(S2:79→117→123;S3:66→93→109)——重叠本应帮忙,却变差;
- **sASM:迭代数随 overlap 下降**(S2:79→73→71;S3:66→55→53)——符合预期;
- O=0 时两者相同(无重叠→无重数差异)。

## 4. 我的诊断(请审阅、指错、补充)

- **谱框架**:$\kappa\le C_0^2\,\omega\,(\hat N+1)$(Toselli–Widlund;显式常数见 Gander–Halpern–Santugini 2015),$\lambda_{\min}\ge1/C_0^2$、$\lambda_{\max}\le\omega(\hat N+1)$。
- **overlap 反常的机制**:$\hat N$ = 重叠区**过计数**(一个 dof 被多个子域各修一次)→ ASM 里 $\lambda_{\max}$ 随重叠涨 → CG 变慢。**sASM 的 $D^{-1/2}$ 按重数摊回 → $\lambda_{\max}\to$ ~1.5 → 重叠转为帮忙。** 过计数是 **λmax 侧**的病。
- **sASM 之后的真瓶颈在 λmin**:实测 S2 λmax≈1.5(已好)、λmin≈0.005、**cond≈300 全来自 λmin**;最小端约 **12 个孤立小特征值**。残差呈**快头(~5 步压掉 λ≈1 的主体)+ 慢尾(~62 步磨那 12 个小模)**。S3 ~8 个;S1 无(平凡)。
- **这 12 个慢模是几何的**:把各向异性张量改各向同性,S2 迭代不变(67=67)——最慢模是**沿最长轴的最长波**,$\lambda_{\min}\sim\sigma_L(\pi/L_x)^2$,与各向异性比无关。
- **一批否定结果(共性:都在 λmax 侧,碰不到 λmin)**:界面传输条件优化(Robin)在 ICC(0) 下收益归零;非装配 Neumann+Robin 块被 overlapping-sASM 支配;纯 Neumann 子域"越准越糟";单向量初值 −2%。
- **信息传递视角**:椭圆残差瞬间全局,但局部预条件的 Krylov 射程每迭代只长一个子域,全局归约不延长射程 → 全局慢模要 ~N 跳 → 单层不扩展。
- **结构馈赠**:S2/S3 每步重解同一算子(仅 RHS 变)→ Krylov 回收/deflation 学出 ~12/~8 维慢子空间。实测回收 **−77%(4.5×)**;单向量初值仅 −2%。
