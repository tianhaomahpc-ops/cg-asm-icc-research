## 第0节 例子本体:三颗珠子的链

一根两端钉死的弦上挂 3 颗珠子,第 i 颗竖直偏移量记 x_i(珠子简图可看图1左:横轴就是珠子编号)。

**力的规则(唯一的物理输入)**:每段弦像橡皮筋,把珠子往邻居的位置拉,拉力 = 两端偏移之差。以珠子 1 为例,它左边是墙(偏移 0)、右边是珠子 2,所以被拉回的合力:

```
(x1 − 0) + (x1 − x2) = 2·x1 − x2
```

——**对角线的 2 和旁边的 −1 就是这么来的**(一个 x1 出现两次、邻居各减一次)。三颗珠子的平衡条件"拉回力 = 外力":

```
2·x1 − x2        = b1
−x1 + 2·x2 − x3  = b2
      −x2 + 2·x3 = b3
```

写成矩阵 A·x = b:

```
A = [ 2 −1  0]
    [−1  2 −1]
    [ 0 −1  2]
```

取外力 b = (1, 0, 1)(两端珠子各被拉一把)。**答案是 x* = (1,1,1)**(整条链抬高 1),验证:A·(1,1,1) = (2−1, −1+2−1, −1+2) = (1,0,1) ✓。

> 后面所有概念都在这一个 A、这一个 b 上讲;§4 把同一种链加长到 100 颗珠子(矩阵规则不变:对角 2、邻居 −1)。

## 第1节 迭代法

**定义** 迭代法 = 一条只用"A 乘向量"的规则,把猜测 x 反复改进,直到满足方程。之所以只许乘:真实问题 A 有百万行,"除以 A"(求逆)做不起,乘一次却很便宜。

**具体做法** 拿到猜测 x,先代入方程看差多少,这个差叫**残差**:

```
r = b − A·x        (r=0 就解完了)
```

差了就补:如果 A 是"乘 1",那 x+r 一步到位;A 不是 1 但方向大致对,所以只走一小步:

```
x ← x + α·r
```

α 是步长。§3 会证明:α 只要小于 0.586 都收敛,这里先用 0.25(让算术好看,没有别的特殊性)。

**在例子里跑**(从 x=(0,0,0) 开始;`tutorial_chain.py` 打印):

| 步 | r | x | 误差 e = x − x* |
|---|---|---|---|
| 1 | (1, 0, 1) | (0.25, 0, 0.25) | (−0.75, −1, −0.75) |
| 2 | (0.5, 0.5, 0.5) | (0.375, 0.125, 0.375) | (−0.625, −0.875, −0.625) |
| 3 | (0.375, 0.5, 0.375) | (0.469, 0.25, 0.469) | (−0.531, −0.75, −0.531) |

(误差整体怎么缩,图1右会拆开看。)每一行都是"代入、看差、补一小步"。误差确实在缩,但**中间分量缩得慢**。为什么?哪个部分快、哪个部分慢?这个问题迭代规则自己回答不了——需要下一个概念。

## 第2节 模(特征向量)、特征值、谱

**定义** 若某方向 v 满足 **A·v = λ·v**(乘 A 的效果 = 乘一个普通数 λ),则 v 叫特征向量(下文叫**模**),λ 叫它的特征值。

**在例子里找到它们**(不用理论,乘一下就验证;√2≈1.414):

```
A·(1, √2, 1)  = (0.586, 0.828, 0.586)  = 0.586·(1, √2, 1)     → λ1 = 2−√2 = 0.586
A·(1, 0, −1)  = (2, 0, −2)             = 2·(1, 0, −1)         → λ2 = 2
A·(1, −√2, 1) = (3.414, −4.828, 3.414) = 3.414·(1, −√2, 1)    → λ3 = 2+√2 = 3.414
```

**模的形状**(图1左,把每个模画成三颗珠子的偏移)。数一数各模里**符号翻转几次**:
- 模1 (1,√2,1):三颗同向,0 次翻转 → 一个**平滑鼓包**。借波的说法叫"1 个半波"(半波 = 一段不变号的鼓包),它对应的波最长;
- 模2 (1,0,−1):翻转 1 次 = 2 个半波;
- 模3 (1,−√2,1):翻转 2 次,正负交替的**锯齿** = 3 个半波,波最碎。

**规律:翻转越少(波越长)λ 越小;翻转越多(波越碎)λ 越大。** 物理直觉:锯齿把相邻珠子拽向相反方向,相邻偏移差大 → 按 §0 的力规则,回拉力猛(λ 大);平滑鼓包相邻偏移几乎相同 → 回拉力弱(λ 小)。

**定义(谱)** 谱 = 全部特征值的集合。本例谱 = {0.586, 2, 3.414}。
**谱分布/谱的形状** = 这些数在数轴上怎么排。
**条件数** κ = λmax/λmin = 3.414/0.586 = 5.83,衡量"最快与最慢差多少倍"。

**误差怎么按模拆开(和第1节接上)**。先补一个只是"乘加"的运算:

> **定义(点积)** 两个向量的点积 = 对应分量相乘再加起来:u·v = u1·v1 + u2·v2 + u3·v3,结果是一个数。
> **单位化** = 把模除以自己的长度(长度 = 自己点积自己再开方)。|(1,√2,1)| = √(1+2+1) = 2,所以
> v̂1 = (0.5, 0.707, 0.5),同理 v̂2 = (0.707, 0, −0.707),v̂3 = (0.5, −0.707, 0.5)。

这三个模**互相垂直**(点积验证:v1·v2 = 1·1+√2·0+1·(−1) = 0,同样 v1·v3 = 0,v2·v3 = 0)。正因为互相垂直,任何向量都能唯一拆成三个模的组合,且**系数 = 和单位模的点积**(垂直保证各模互不干扰,一个系数一个模)。拆初始误差 e0 = −(1,1,1):

```
c1 = e0·v̂1 = (−1)(0.5)+(−1)(0.707)+(−1)(0.5) = −1.707    (慢模成分)
c2 = e0·v̂2 = (−1)(0.707)+0+(−1)(−0.707)      = 0         (本例恰好不含模2)
c3 = e0·v̂3 = (−1)(0.5)+(−1)(−0.707)+(−1)(0.5) = −0.293    (快模成分)
```

## 第3节 核心对应:迭代 = 每个模独立打折

**断言** 第1节的规则 x ← x + α·r,在模坐标下**完全解耦**:每个模的误差系数每步乘一个固定折扣

```
新系数 = (1 − α·λ) × 旧系数
```

**三行推导**(对一个模,b = λ·答案):
```
新x = x + α·(b − λ·x)
新e = 新x − 答案 = (x − 答案) − α·λ·(x − 答案) = (1 − α·λ)·e
```

**在例子里对账**(全文最重要的一步)。同一个第 2 步,两条路算:

- **直接路**(只用第1节规则,不知道任何特征值):§1 表第2行,e2 = (−0.625, −0.875, −0.625)。
- **模路**(用打折公式预测):
  - 模1 折扣 1−0.25×0.586 = **0.854**,两步后系数 −1.707×0.854² = −1.244
  - 模3 折扣 1−0.25×3.414 = **0.146**,两步后系数 −0.293×0.146² = −0.006
  - 拼回:−1.244·v̂1 − 0.006·v̂3
       = −1.244·(0.5, 0.707, 0.5) − 0.006·(0.5, −0.707, 0.5) = **(−0.625, −0.875, −0.625)** ✓

**两条路数字一模一样**(脚本逐项打印)。这就是"特征值与求解的对应关系":迭代表面上在算残差走步,**实际效果精确等于每个模按自己的 λ 打折**。第1节"中间分量掉得慢"的谜底:中间分量主要属于模1(λ 最小,折扣 0.854 贴近 1)。

**α 能取什么**(顺带解决"α 为什么是 0.25"):折扣要缩小需 |1−αλ|<1 对**每个** λ 成立,最卡的是 λmax:

```
α < 2/λmax = 2/3.414 = 0.586        上限是算出来的,不是选的
```

区间 (0, 0.586) 里任取都收敛;0.25 只是其中一个方便的值。且**调 α 救不了慢模**:α 越大模1折扣越小,但 α 一逼近上限模3先出问题;怎么折中,模1 的折扣都贴着 1。

**每模步数**(图1右;"到 0.000001"意思是该模系数缩到初始的百万分之一,即反复 ×0.854 到不足百万分之一):模3 → 8 步,模2 → 20 步(注:本例模2成分恰为 0,不参与,这是它的固有速率),**模1 → 88 步**。整体步数由最慢的模决定 = 88 步。

> **小结:谱在数轴上的位置 = 每个模的收敛速度表。λ 大的模是快头,λ 小的模是慢尾。**

## 第4节 链加长:谱的形状就是步数的地图

同一种链加长到 **n=100** 颗珠子(矩阵规则不变:对角 2、邻居 −1)。模还是驻波(振动形状:1 个半波、2 个半波、…、100 个半波),谱变成 100 个数:

```
λ1 = 0.000967(最长波)  …  λ100 = 3.999(最碎波),κ = 4134
```

**谱的形状**(图2①):右端一大坨挤在一起(碎波,好解);左端**稀薄的尾巴**——最小的 8 个 λ = 0.0010, 0.0039, 0.0087, 0.0155, 0.0241, 0.0347, 0.0472, 0.0616(红圈)。难度全在这条尾巴:κ 的分母就是尾巴最左那个点。

一处诚实的改动:n=3 的 b=(1,0,1) 几乎只激发模1(c2=0),放到 n=100 会只点亮一列,看不出全谱;所以 §4 换成一个**激发所有模的一般右端项**(脚本里用随机 x* 生成),矩阵和模完全不变。

**求解实况的可视化**(图2②,读法):热力图**每一行=迭代的一步(从上往下),每一列=一个模(横轴按 λ 排,和①同一根轴),颜色=该模误差还剩多少(亮=还在,黑=已解掉)**。竖着对齐:①里红圈的 λ,正对②里"一直亮着"的那几列。

这里求解器换成实际使用的 **CG**。和 §1 规则的关系:§3 已经证明简单迭代 k 步后每模残余 = (1−αλ)^k——这是一个"λ 的多项式,且在 λ=0 处取值 1"。CG 是它的聪明版:**不用手选 α,每步自动配最优组合,等效于把 (1−αλ)^k 换成一个更会压低的多项式 p_k(λ)**;但两条天条不变——只能乘 A,以及 p_k(0)=1(原因:λ=0 的模乘 A 永远得 0,迭代碰不到它,它的残余只能是 1)。所以"大 λ 快、小 λ 爬"的结构原样保留。结果(图2②):右边整片几步变黑,左边尾巴磨到底,**共 100 步**。

## 第5节 粗空间:对爬不动的模直接做除法

**思路** §3、§4 证明了:慢的就是左端那几个模,而且调 α/换方法救不了它们。但注意——"不能除"是针对整个大矩阵说的;**如果只在几个已知方向上除,方程组小到可以直接解**。

**定义/做法**(四步;先补一个记号:Wᵀ 表示把 W 的行列互换,"竖着的列排成横着的行"):
1. 把 m 个慢模排成瘦高矩阵 **W**(n 行 m 列)。本例 n=100 取 m=8 个最长波。
2. 把 A 压到这 m 个方向上:**E = Wᵀ·A·W**(m×m = 8×8;逐列看仍是矩阵×向量:E 的第 j 列 = Wᵀ·(A·第j列))。
3. E 小,**直接求逆/直接解**——除法在这里做,便宜。
4. 迭代每步在原修正外加一项 **W·E⁻¹·Wᵀ·r**:含义是"残差里属于这 8 个模的部分,不迭代了,当场除掉";初始猜测也先做一次这个粗解。

**效果**(图2③):左边 8 列**从第 0 行起就是黑的**(开局即被除掉),CG 只需要磨剩下的部分:**100 步 → 54 步**。谱的语言:有效谱的最小 λ 从 0.0010 抬到第 9 个 λ = 0.0779,尾巴被铲掉。

**本质一句话**:粗空间不是新魔法,就是**把"除不起"的全局除法,缩小到"除得起"的 m 维小方程**,专门伺候那几个拖后腿的模。

**真实问题里 W 从哪来**(不知道精确特征向量时):
- 用**几何近似**张出慢模:每个子区域一个指示向量(Nicolaides),或每子域 {1, x, y, z}(geometric)。慢模=长波=平滑,平滑函数用分片常数/线性就能近似。我们的实测系统 Sys2 上正是这样做的:测得 12 个慢模的尾巴,fine 76 步 → 加 geometric 粗空间 40 步(数字来自 `forward_ecg.cpp -deflate` 实验,非本教程脚本),与本教程 100→54 是**同一件事在同一结构上的两次发生**。
- 或从**历史解里回收**(recycling):之前解过的解天然富含慢模成分。

## 第6节 关系总图

```
链(物理:拉力=偏移差)
  │ 平衡条件逐珠子写出(2 和 −1 由力规则推出)
  ▼
矩阵 A, 方程 A·x=b
  │ 找"乘A=乘一个数"的方向(乘法可验证)
  ▼
模 v_k(0/1/2 次符号翻转的驻波) + 特征值 λ_k(波越长 λ 越小)
  │ 全部 λ 摆上数轴
  ▼
谱 与 谱的形状(右端一坨 + 左端稀尾巴; κ=λmax/λmin)
  │ 误差按模分解(模互相垂直 → 系数=点积)
  ▼
迭代法 x←x+α·r  ≡  每模独立 ×(1−αλ)   [两条路同数验证]
  │ α < 2/λmax 封顶 → 小 λ 折扣贴 1;CG=换更优多项式,p_k(0)=1 不变
  ▼
快头(大λ,几步黑) + 慢尾(小λ,磨到底) = 步数由谱左端决定
  │ 对慢模不迭代、直接除:W, E=WᵀAW(m×m,除得起), W·E⁻¹·Wᵀ·r
  ▼
粗空间:尾巴开局即黑,100→54 步(实测 Sys2:76→40)
```
