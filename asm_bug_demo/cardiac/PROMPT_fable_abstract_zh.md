# Prompt(抽象数值问题,可直接提问)

## 背景

我在做**稀疏对称正定(SPD)线性系统的并行预条件研究**,目标**强可扩展到 ~3000 核**。问题来自**三维非结构四面体 P1 有限元**离散:一个**细长盒子区域 Ω₁(边长比约 20:7:3)** conforming 嵌在一个**大盒子 Ω₂(50³)** 里。每个时间步**顺序求解三个 SPD 线性系统**:

- **系统 S1(抛物、质量主导)**:$A_1=\tfrac{1}{\Delta t}M+\tfrac12 K_1$(M 质量矩阵、$K_1$ 各向异性扩散刚度,主轴沿最长轴 x)。Neumann 边界。**良态**(条件数 ~1.4,CG ~8 步)。
- **系统 S2(奇异椭圆,主目标)**:$K_2\,u=f$,$K_2$ 各向异性扩散刚度(纵向扩散系数 ≫ 横向)。**纯 Neumann → 奇异**(零空间 = 常数),用零均值 RHS + 常数核投影处理。**难**(条件数 ~300,CG ~67 步)。RHS 由 S1 的解驱动。
- **系统 S3(椭圆、大区域)**:$K_3\,\varphi=0$,**界面 Dirichlet**(值来自 S2 的解)+ 外边界 Neumann。中等(条件数 ~170,CG ~51 步)。

求解器:**CG + 加性 Schwarz(1 子域/进程,本地不完全 Cholesky ICC)**。规模:每进程数万自由度、进程数很大 → **通信受限区**(每迭代被全局归约 Allreduce 延迟主导)。

## 我已完成的分析(请审阅、指错、补充)

**1. 谱框架**。用经典抽象 Schwarz 界 $\kappa(M^{-1}A)\le C_0^2\,\omega\,(\hat N+1)$(Toselli–Widlund;显式常数见 Gander–Halpern–Santugini, ESAIM M2AN 2015)拆解,且 $\lambda_{\min}\ge 1/C_0^2$、$\lambda_{\max}\le\omega(\hat N+1)$:
- $\hat N$(重叠区过计数,**λmax 侧**)→ 对称多重数缩放(scaled ASM)治好,λmax→~1.5;
- $\omega$(本地解不精确,λmax 侧)→ ICC 阶数;
- $C_0$(全局慢模,**λmin 侧**)→ 粗空间。

**2. 诊断(实测谱)**。S2:λmax≈1.5(已好)、λmin≈0.005、**cond≈300 全部来自 λmin**;最小端约 **12 个孤立小特征值**。CG 残差呈 **"快头(~5 步压掉 λ≈1 的主体)+ 慢尾(~62 步磨那 12 个小模)"**。S3 类似(~8 个小模)。S1 无小模(平凡)。

**3. 慢模是几何的,不是各向异性的**。把各向异性张量改成各向同性(横向系数 := 纵向),S2 迭代数**不变**(67=67)。机理:最慢的模是**沿最长轴 x 的最长波**,$\lambda_{\min}\sim\sigma_L(\pi/L_x)^2$,只由**纵向系数 + 区域长度**定,与各向异性比无关。

**4. 一批否定结果(共同点:都在 λmax 侧,碰不到 λmin)**:
- overlap:缩放后帮忙,但只**常数因子**;
- **界面传输条件优化(Robin 调参)**:近精确本地解下 −30%,**不精确(ICC0)本地解下收益归零**;
- 非装配 Neumann + Robin 块(优化 restricted Schwarz):被"重叠 + Dirichlet 块"支配;
- **纯 Neumann 子域**(奇异局部块):RHS 不相容、"解得越准越糟",归宿是粗空间(Neumann-Neumann/FETI);
- 用 S1 的解外推 S2 的**单向量初值**:仅 −2%(单向量张不成 12 维慢尾);
- 各向异性:对迭代无影响。

**5. 信息传递视角**。椭圆算子的残差瞬间全局,但**局部**预条件的 Krylov 子空间**空间射程每迭代只长一个子域**(最近邻 matvec);全局归约让 CG 最优但**不延长射程**。全局光滑慢模要 ~N 跳才拼出 → 单层 Schwarz 不扩展。

**6. 结构馈赠**。S2/S3 每时间步**重解同一算子**(仅 RHS 慢变)→ 可用 **Krylov 回收 / deflation** 从历史学出那 ~12 / ~8 维慢子空间(= 时间摊销的粗空间)。实测:历史投影型回收 **−77%(约 4.5×)**;而单向量初值只 −2% —— 说明杠杆是"多向量 deflate 慢子空间",不是"更好的初值"。

**7. 一个未闭合的点**。在 np=2/4/8 实测,慢模维**基本恒定(~12)**、cond 也基本不变(~290)—— **尚未进入 $C_0$ 随子域数 N 增长的渐近区**;真实强扩展曲线未跑过。
