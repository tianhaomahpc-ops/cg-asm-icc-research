## 1. 问题定义

心脏前向 ECG:每个时间步(EP 循环,约 10³–10⁴ 步)依次解三个线性系统。参数 [实测]:
χ=140/mm, C_m=0.01, χC_m=1.4;σ_mono=(0.1334,0.0176), σ_i=(0.17,0.019), σ_e=(0.62,0.236), σ_o=0.22 mS/mm;各向异性纵横 ~7:1;几何 slab 20×7×3 mm。

| 系统 | 方程 | 算子 | 性质 |
|---|---|---|---|
| **Sys1** 单域 Vm | 时间步 | A₁ = (1/dt)M + ½·Diffusion(σ_mono) | SPD,质量主导,平凡 |
| **Sys2** u_e 恢复 | K_{σi+σe} u_e = −K_{σi} V_m | A₂ = Diffusion(σ_i+σ_e) | **奇异**(ker=span{1}),**最难**,每步重解 |
| **Sys3** 躯干 | 躯干 Laplace | A₃ = Diffusion(σ_o) | SPD,Dirichlet 锚定 |

**关键结构**:A₂ 在整个 EP 循环里**恒定**,只有右端随 V_m(t) 漂移。这是回收/一次性谱 deflation 成立的全部前提。

## 2. 方法的数学表达

**主控不等式**(抽象 Schwarz,Toselli–Widlund):

$$\kappa(M^{-1}A)\;\le\; \underbrace{C_0^2}_{\text{粗空间}}\;\cdot\;\underbrace{\omega}_{\text{本地解精度}}\;\cdot\;\underbrace{(\hat N+1)}_{\text{过计数}}$$

- **N̂** = 覆盖任一点的最大子域数(加性求和的过计数)→ **sASM** 治;
- **ω** = 本地解不精确度(A_i⁻¹ 近似质量)→ **overlap + ICC(L)** 治;
- **C₀** = 稳定分解常数,随子域数增长 → **粗空间 / deflation / 回收** 治。

**ASM 基线**(过计数,重叠让迭代↑): $M_{\text{ASM}}^{-1}=\sum_{i=1}^N R_i^\top A_i^{-1} R_i,\quad A_i=R_i A R_i^\top,\quad \lambda_{\max}\le\omega(\hat N+1)$

**sASM(本研究主用)**,对称重数缩放,消过计数:

$$\boxed{\,M_{\text{sASM}}^{-1}=D^{-1/2}\Big(\textstyle\sum_i R_i^\top A_i^{-1} R_i\Big)D^{-1/2},\quad D=\mathrm{diag}(m(j)),\ m(j)=\#\{\text{覆盖 dof }j\text{ 的子域}\}\,}$$

单位分解条件 $\sum_i R_i^\top D_i R_i=I$;重数权 $D_i(j)=1/m(j)$ 自动满足。效果:λmax→~ω≈1,重叠正常生效。**[理论+实测]** 注:代数 PCASM 里系数权 ≡ 重数权(主子阵对角与子域无关),故系数权只在非装配 Neumann 块(SORAS)才不同。**[实测 -weightcmp]**

**粗空间 / deflation**:取慢模张成 W(n×m),粗算子 E=WᵀAW,修正

$$M_{\text{2lvl}}^{-1}r = M_{\text{fine}}^{-1}r + W E^{-1} W^\top r,\qquad \text{deflated-CG 投影 } P=I-W(W^\top A W)^{-1}W^\top A$$

W 来源:Nicolaides(每子域 1 指示)、geometric {1,x,y,z}、GenEO(每子域广义特征模 λ<τ)、或**回收**。

**Fischer 回收 / cb-Fischer**(§见 DESIGN §11):基 {p_i} A-正交归一,初值

$$x_0=\sum_i \langle p_i,b\rangle\,p_i\quad(=\ x^*\text{ 在 span}\{p_i\}\text{ 上的 A-正交投影});$$

维护:新解对 {p_i} 做 CGS2 再正交、A-归一、滑动窗口淘汰最老。**cb-Fischer** = 所有内积打包成每次求解 O(1) 次 Allreduce(见 §5)。

## 3. 结果(全部 [实测],np=8 除非注明)

**谱诊断 `-decay`**(sASM O1 ICC0):

| 系统 | 迭代 | cond | λmin | λmax | 慢模数(λ<0.1λmax) |
|---|---|---|---|---|---|
| Sys1 | 8 | 1.4 | 0.83 | 1.19 | **0**(平凡) |
| Sys2 | 67 | 293 | 0.0051 | 1.50 | **12** |
| Sys3 | 51 | 172 | 0.0082 | 1.41 | 8 |

cond=293 **完全**由 λmin 那 12 个近零光滑全局模造成(λmax 才 1.5,已被 sASM 治到~1)。**各向异性不增难**(iso 67 = aniso 67;aniso 的 cond 反而更低)→ 难度来自几何最长轴,非纤维比。**[实测 -anisocmp]**

**ASM vs sASM `-precond`**:overlap 下 ASM 迭代↑(过计数)、sASM 迭代↓;sASM ~1.6× 优于 ASM,每迭代耗时相同(加权免费)。

**杠杆 `-fair`**(Sys2):sASM O0 ICC0 76 → O2 ICC2 **33**。**粗空间 `-deflate`**:fine 76 → Nicolaides 59 → geometric **40**(几何见顶)。**GAMG**:7–10 且随 P 平。

**回收 `-fischer`**(EP 循环 T=80ms,Sys2 总迭代):cold 7530 → Fischer **1361–1660(−63~−82%)**,80 步中 50–65 步 0 迭代;**双峰**(易步→0,难步仍~92)。**cb-Fischer 改造**:维护 Allreduce 2252→**314(7.2×↓)**,且 CGS2 顺带再降 45%。

**慢模维数 scaling** `slowdim_scaling.py`:慢模数 ≈ **O(子域数)**(~1.5/子域),加密不 ∝N;薄壁/峡部 +6、高对比疤痕 +3 个 Nicolaides 抓不到的硬模。**[实测玩具]**

**集群强扩展**(用户实测 384/768/1536):Sys2 迭代 107/113/116(**~P^0.055**,极温和);时间近理想~超线性(cache);外推 3072≈120。

## 4. 结论

1. **难度被完全定位**:sASM 已把 N̂、ω 治好(λmax→~1);全部剩余难度 = **一个 8–12 维几何慢子空间**(λmin 尾巴,沿最长轴,对各向异性鲁棒)。**迭代数的唯一杠杆就是这条尾巴。**
2. **一层 sASM 的可扩展性足够撑过 3000 核**(迭代 ~P^0.055,外推 16k 核也才~131)——"3000 核必须粗空间"是**过强**的,已修正。
3. **粗空间从"必需"降为"压绝对迭代数的 2×+ 优化"**;回收是当下性价比最高的下一步(零扩展风险)。
4. **Sys1 平凡**,只需最便宜档,勿加粗空间/回收。

## 5. 3000 → 16000 → 48000 核计划

**每迭代成本**([模型],主导项是 Allreduce):

| 项 | P=3000 | 说明 |
|---|---|---|
| SpMV / ICC apply / halo | ~1–36 µs | 本地,Amdahl 可忽略 |
| **2 点积 Allreduce** | **40–100 µs** | 主导;树模型预测仅~5µs → 真实地板是拥塞/抖动 |

**关键外推**([模型],算术已核):

| P | 一层迭代(P^0.055) | 粗空间维 m=cP | 存活的粗解 |
|---|---|---|---|
| 3000 | ~120 | 3k–15k | 冗余稀疏(~40µs)/子通信器 |
| **16000** | **~131**(不爆) | 16k–80k | **仅子通信器(100–230µs,勉强)** |
| **48000** | ~140 | 48k–240k | **无 → 必须递归(3 层)** |

**拐点**:m=cP 越过冗余稀疏死亡线 m≈15k ⇒ **P≈5k–8k(rich)~15k(lean)必须转 GenEO 多层**。即:**迭代数不是一层的死因,m=O(P) 的粗解才是。**16000 核多层已是强制。

**分层处方**:
- **P ≲ 3000**:一层 sASM + overlap + ICC + **回收**(cb-Fischer),粗空间可选。
- **P ≈ 5k–48k**:**GenEO 多层**(≈40–50 迭代,随 P 平,provable κ≤(1+k₀)[2+k₀(2k₀+1)(1+H/δ)])+ 回收 + pipelined CG;粗解递归(AMG-on-coarse / 子通信器)。
- **前提**:16k 核要高效需 **≥1e10–1e11 dof**(本地工作 ≥20% 迭代预算,~3–6e6 dof/核);否则撞强扩展延迟墙——**少用核也是答案**。
- **摊销**:算子恒定 ⇒ GenEO/ICC 的 setup(0.1–1s)被 10⁴ 步摊成每步 ~2–20%,可行;**若算子每步变(非线性/动网格)则摊销失效**。

## 6. 还有多少改进空间?(对抗式排名,measured 优先)

### 6A. 降迭代数(唯一战场 = λmin 尾巴)

| 杠杆 | 预期 | 依据 | 判定 |
|---|---|---|---|
| **① 固定谱 deflation**:一次性算 12–40 个最小特征向量冻结,deflated-CG 每步投影 | 67 → **~10–18(确定性)** | 恒定算子 [模型],复用现有 GlobalDeflate+SLEPc | **最高:一次特征解喂上万次求解,压过自适应回收** |
| **② AMG(GAMG)作粗层/独立** | 67 → **7–10,随 P 平** | [实测 GAMG];恒定算子 → setup 反对无效 | **最高:~7× 且天然可扩展** |
| **③ 维护型 deflation-CG / GCRO-DR 取代 guess-only Fischer** | 消掉双峰的难步(~92→~15) | [实测双峰] | **高:现在难步白白付全价** |
| **④ 粗空间 × Fischer 在 EP 循环里合用(从未同跑)** | 难步→40(Nicol)/~15(谱),乘性 | 两者只分开测过 | **高:免费的组合实验** |
| ⑤ GenEO 谱粗空间(真实几何) | 40 → ~10,治薄壁/疤痕硬模 | [实测硬模];需真几何 | 中(值在真实心脏几何) |
| ⑥ 一次性高精度本地分解(ICC2-3/精确 Chol) | 收紧 ω,让 overlap 真正兑现 | 恒定算子 [实测] | 中 |
| ⑦ 几何感知分区(长宽比→1,勿切薄壁) | 减少沿长轴界面 + 少硬模 | [实测 slowdim] | 中(一次性,免费叠加) |
| ⑧ 优化 Robin/SORAS 传输 | ICC0 下甜点被抹平 | [实测 -transmiti] | **低:大规模用 ICC 时白调** |
| ⑨ 物理初值(Sys1→Sys2 / x0=c·Vm) | **−2%** | [实测] | **弱:单向量张不成 12 维尾巴** |

**要点**:**几何粗空间已在 40 见顶(rich {1,x,y,z} 也是 40)**;40→~10 只有 **AMG / 谱 deflation / GenEO** 三条路,且都因**算子恒定**而 setup 免费。

### 6B. 降时间(唯一战场 = Allreduce,本地加速被 Amdahl 封顶)

| 杠杆 | 预期 | 判定 |
|---|---|---|
| **pipelined CG(PIPECG/GROPPCG)** 重叠 Allreduce 与计算 | 隐藏延迟;**须开 MPI 异步进度否则名存实亡** | **一级:本机已验证可用** |
| **node-aware / 分层 collective + SHARP + 环境调优** | 削每次 reduce 的 log P | **一级:零代码,乘性** |
| **摊销全部 ICC/ASM/GenEO setup**(恒定算子) | setup/10⁴步 → 0 | **一级:确认循环没在每步重装** |
| `-ksp_cg_single_reduction`(2→1 归约) | 安全,无需异步进度 | 一级 |
| 匹配 dof/核到 cache-延迟甜点 / 少而肥的 rank | 削 Allreduce 参与者数 | 一级(强扩展前提) |
| Chebyshev-Jacobi 替 ICC(免分解 setup + 无三角解串行) | 每 apply 更便宜、GPU 友好 | 二级:需改被钉死的 pc_type |
| **Chebyshev 外迭代(0 归约/迭代)** | 延迟杀手最大化,险 | 二级:激进,需谱界 |
| 融合 Sys1/2/3 的标量到 1 次打包 Allreduce | ~3× 归约数 | 二级(算子分裂依赖允许时) |
| **打包一切独立标量到单次 Allreduce**(cb-Fischer 已证 7.2×) | 通用纪律 | **横切:所有 reduce 都照做** |
| mixed precision fp32 PC / GPU 卸载 SpMV+ICC | 攻错了片(延迟主导);ICC 三角解 GPU 敌对 | **陷阱:仅在"少肥 rank+Chebyshev+GPU-MPI"重设计里才值** |
| s-step/CA-CG | 理论削同步最狠但本机无 HPDDM、数值脆 | 天花板/需重编 |

## 7. 一句话总纲

**难度已被压成一个 8–12 维几何慢子空间(λmin 尾巴):sASM 治好了 λmax,几何粗空间到 40 见顶,再往下(→~10)靠的是"算子恒定 → setup 免费"的 AMG / 一次性谱 deflation / GenEO,并把 guess-only Fischer 升级成维护型 deflation 与粗空间在 EP 循环里合用(乘性);可扩展性上,一层迭代数到 16k 核也才~131 不爆,真正的拐点是 m=O(P) 的粗解在 P≈5–8k 崩溃 → 强制转 GenEO 多层,配 pipelined CG + node-aware collective + 打包一切归约 + 恒定算子的 setup 摊销;前提是给这些核数配 ≥1e10 dof,不够就少用核。改进空间明确、可测、且大部分因"同一算子解上万次"而近乎免费。**
